# HENRICHED DIGITAL SERVICES

A professional digital services ordering and business management platform.

## Planned features

- Digital services catalogue
- Customer enquiries and order management
- Paystack payment integration
- Secure administrator dashboard
- WhatsApp contact integration
- Order status tracking
- Responsive mobile-first interface

## Architecture

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- Payments: Paystack
- Hosting: Render

## Security

Payment secret keys and administrator credentials must be stored as server-side environment variables. Never commit secrets to Git.
